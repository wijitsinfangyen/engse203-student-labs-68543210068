## คำอธิบายโครงงาน
เว็บแอปพลิเคชันแสดงรายการแผนการเรียนรู้ พัฒนาด้วย Vanilla JavaScript (ES Modules) ร่วมกับ Vite โหลดข้อมูลแบบ Async ด้วย Fetch API มีระบบกรองข้อมูล คำนวณสรุปผล และจัดการ Error State
